# Postman collection

A Postman collection is available for testing the components. It runs
against the service created with the `make clean build run` command — see [Setup](/introduction/setup) and [Getting started](/introduction/getting-started) to get the stack running locally.

Download the [Postman collection](https://github.com/openfort-xyz/opensigner/blob/main/docs/public/postman/keys.json).

The collection covers the [authentication service](/apis/auth_service), [hot storage](/apis/hot_storage), and [cold storage](/apis/cold_storage) endpoints.
