# Getting started

After completing [Setup](/introduction/setup) and starting the components (for example, with `make run`), you can start using the OpenSigner service.

Open the [iFrame](/components/iframe) in your browser (running on port 7050 by default) or explore the [Postman collection](/apis/postman). From there, follow [Create a key](/actions/signup) to create your first wallet, then [Recover a key](/actions/login) and [Use a key](/actions/operation) to exercise the full flow.

If you already issued keys with Openfort and want to migrate, see [Import shares from Openfort](/introduction/import-share-from-openfort).
