## What you can do with OpenSigner

OpenSigner is a self-hostable wallet signer that splits each user's private key into three shares using Shamir's Secret Sharing — one share lives on the user's device, one in [hot storage](/components/hot_storage), and one (encrypted) in [cold storage](/components/shield). The full key is only ever reconstructed in-memory inside the [iFrame](/components/iframe), then immediately discarded.
